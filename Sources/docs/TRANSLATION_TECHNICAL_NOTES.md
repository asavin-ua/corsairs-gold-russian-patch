# Русификатор Corsairs Gold

Актуальная рабочая документация на 13 сентября 2026 года. Папка
`Russian_Patch` содержит исходники переводов, установщики, диагностические
инструменты и резервные копии. Корень игры не является Git-репозиторием.

Структура каталога:

```text
Russian_Patch\
├── README.md       — эта документация
├── backup\         — неизменённые игровые ресурсы
├── translations\   — UTF-8-исходники переводов
├── scripts\        — установщики, генераторы и восстановление
└── tools\          — Python-инструменты, CRK-кодек и локальные зависимости
```

  массовая проверка сравнивает структуру,
  число строк и установленные CP1251-файлы с UTF-8-исходниками.
- собран автономный каталог `releases\Corsairs_Gold_Russian_Patch_1.0_2026-09-13`:
  112 готовых ресурсов, безопасный однобайтовый патч `corsairs.exe`, автоматический

английский суффикс или латинскую букву внутри русского слова. После патча они не
нужны.

Для контрольной сборки всех подготовленных событий первого MSG:

```powershell

```

Режим `Full` защищён подтверждающим флагом. Для рабочего файла достаточно
обычного режима `Install`, который использует явный список из 50 строк.

## Автономный выпуск

Готовый распространяемый каталог:

```text
Russian_Patch\releases\Corsairs_Gold_Russian_Patch_1.0_2026-09-13
```

Он не содержит оригинальный исполняемый файл игры. Установщик принимает путь
через `-GamePath` либо ищет Corsairs Gold в текущей папке, стандартных каталогах
и реестре. Поддерживается английский `corsairs.exe` с SHA-256
`93FD792E80EC085F36BE814A4A244E96FDCB32CE3010F7B91064836C7FC02FE2`;
для неизвестной версии установка прерывается без изменений.

В выпуск входят команды установки и проверки. Обычный
`Install_Russian_Patch.cmd` не сохраняет исходные файлы: предполагается чистая
установка игры. Необязательный `Install_With_Backup.cmd` создаёт
`Russian_Patch_Backup_1.0` с контрольными суммами всех 113 затрагиваемых файлов;
только после этого доступно восстановление через `Uninstall_Russian_Patch.cmd`.
Тест на чистой временной копии подтвердил оба режима и побайтовое восстановление.

В выпуск также входит каталог `Sources` со всеми 108 UTF-8-исходниками INT/MSG,
скриптами, генераторами шрифтов, инструментами и исходниками автономного
установщика. `Prepare_Translation_Workspace.cmd` переносит их в папку игры без
резервных копий. После редактирования `install_edited_translations.ps1` напрямую
преобразует и устанавливает все 108 UTF-8-исходников как Windows-1251/CRLF.
Таким образом перевод можно исправлять и повторно собирать без включения
оригинальных игровых файлов в публикуемый каталог.

Повторная сборка выпуска из текущего проверенного состояния:

```powershell
& '.\Russian_Patch\scripts\build_portable_patch.ps1'
```

## Принятые правила перевода

- Игровые текстовые ресурсы записываются в Windows-1251 со строгими окончаниями
  строк `CRLF`.
- Исходники переводов в `Russian_Patch\translations` хранятся в UTF-8.
- Нельзя напрямую копировать UTF-8-файл поверх игрового `.ENG`.
- Не использовать длинное тире `—` (U+2014) в игровых текстах: книжный шрифт
  отображает его как посторонний символ. Вместо него использовать обычный дефис,
  двоеточие или запятую; проверочный скрипт отклоняет U+2014 в файлах миссий.
- Не переводить динамические и скриптовые имена, включая названия кораблей
  (`LE FRINGANT`).
- Не переводить обозначение валюты `GP`.
- Заголовок панели `Messages.` переводится как `Сообщения.`, а
  `Targets to reach.` — как `Цели.`. Содержимое сообщений и целей переводится
  отдельно.
- На городском экране `PURCHASE` / `SALE` переводятся как `ПОКУПКА` / `ПРОДАЖА`.
  Числовые записи 065–097 содержат контекстные подсказки городских действий и
  навигации.
- Названия товаров `Sugar Cane`, `Silk` и другие нанесены на изображения и не
  меняются переводом CRK. Динамические имена городов в файлах миссий пока не менять.
- Названия городов в MSG не переводить: они должны точно совпадать с картой и
  городским экраном (`Saint Eustatius`, `San Juan`, `Saint Croix`, `Vieques`,
  `Saint Martin`). Русский текст вокруг них переводится как обычно.
- Для проверки стартовых сообщений полностью перезапускать игру и начинать
  новую французскую кампанию.

Коды стран в каталогах миссий:

| Код | Страна |
| --- | --- |
| `RED` | Англия |
| `BLU` | Франция |
| `ORA` | Голландия |
| `YEL` | Испания |

## Исправление парсера MSG

### Первопричина

Оригинальная функция `corsairs.exe` по адресу `0x0042C675` считает буквами и
цифрами только ASCII `A-Z`, `a-z` и `0-9`. При полностью кириллическом тексте
Windows-1251 поиск следующего маркера `ACTI` / `REAL` / `FAIL` / `[OBJ`
перескакивает через тело сообщения и обрезает его после имени отправителя.

Исправление меняет один байт в `corsairs.exe`:

- файловое смещение: `0x2BC7D`;
- исходный байт: `0x7C` (`JL`, знаковое сравнение);
- новый байт: `0x72` (`JB`, беззнаковое сравнение).

После патча расширенные однобайтовые символы, включая CP1251, больше не
считаются разделителями. Патч рассчитан только на проверенную версию файла:

- SHA-256 оригинала:
  `93FD792E80EC085F36BE814A4A244E96FDCB32CE3010F7B91064836C7FC02FE2`;
- SHA-256 после патча:
  `2070286F84C78EDC7C6BC70CC774293EAD36B4BB3B5E5C76860BE1EF231824F4`.

Скрипт откажется менять неизвестную версию исполняемого файла.

### Установка и откат патча

```powershell
# Проверить состояние без изменений
& '.\Russian_Patch\scripts\patch_msg_parser.ps1' -Mode Inspect

# Создать резервную копию и установить патч
& '.\Russian_Patch\scripts\patch_msg_parser.ps1' -Mode Apply

# Восстановить оригинальный exe
& '.\Russian_Patch\scripts\patch_msg_parser.ps1' -Mode Restore
```

Оригинал сохраняется в
`Russian_Patch\backup\corsairs.msg-parser-original.exe`.

### Формирование MSG

Штатные языковые варианты одного MSG имеют разные размеры, поэтому сохранять
исходную длину каждой текстовой строки не требуется. Дополнение короткого
перевода пробелами создаёт пустые визуальные строки и запрещено для рабочего
перевода. Латинские буквы внутри русских слов после патча также не нужны.

Рабочий файл первого сообщения:
`data\missions\MIS01\BLU\MSG\MIS01BLU.ENG`.

Текущее состояние файла:

- кодировка Windows-1251;
- 108 окончаний `CRLF`;
- размер 4013 байт;
- SHA-256: `69947680A9E3658477F7F546F5DE8596E1397A6FB377B30230C2C8D6BEEA8A3F`;
- изменены только 50 явно выбранных физических строк: 4–6, 8–9, 13–15,
  18–19, 23–25, 29, 33–36, 39–41, 44, 48–50, 55–56, 60–62, 66–69,
  73–74, 76–78, 80, 85–87, 89, 94–96, 100–101 и 104;
- в конце русских строк нет пробельного заполнения;
- латиница встречается только в оставленных без перевода названиях городов и
  других явно разрешённых игровых именах.

Установленный для проверки текст:

Отправляйтесь в Saint Eustatius и свяжитесь с губернатором.
Он только что получил новые распоряжения короля и сообщит вам, что нужно сделать, чтобы достойно послужить нашей стране.

Для всех подготовленных MSG используется массовый установщик. Он сам находит
UTF-8-исходники, создаёт резервные копии оригиналов и собирает каждый игровой
файл целиком без пробельного заполнения:

```powershell

```

`Russian_Patch\translations\MIS01_BLU_MSG_MIS01BLU.utf8.txt`.

`tools\analyze_msg_parser.py` воспроизводит статический анализ исполняемого файла.

## Интерфейс и шрифты

Игра использует скомпилированный ресурс `data\CRK\L_ENGLIS.CRK`. Наличие рядом
`L_ENGLIS.INI` не заставляет игру предпочесть INI.

Основные файлы:

- `data\CORS3.F32` — крупные надписи меню;
- `data\CORS1.F32` — небольшие надписи интерфейса;
- `data\BOOK.F32` — книжные описания и сообщения.

Генераторы:

- `scripts\cors3_cyrillic.ps1`;
- `scripts\cors1_cyrillic.ps1`;
- `scripts\book_cyrillic.ps1`.

Кириллица `BOOK.F32` сейчас строится шрифтом Georgia размером 16 пикселей с
дополнительным интервалом 1 пиксель. Этот вариант проверен в игре. Глифы `П` и
`Ц` в CORS3 исправлены вручную; в CORS1 добавлены отсутствовавшие прописные `Б`,
`Д`, `Ж`, `Й`, `П`, `Ц`, `Щ`, `Я` и строчные буквы для заголовков панелей. Не заменять
проверенные шрифты без отдельной причины.

Исходный `CORS1.F32` заканчивается символом Windows-1251 `0xE1`. Генератор
расширяет таблицу до `0xFF`, обновляет размер файла и смещение растров, после чего
добавляет строчные глифы. Установленный `CORS1.F32` имеет SHA-256
`0D0FCD6E78F4561D21235B7F1CB9C4461CDB2CB66A3E7E4E58F1AA8CBC199C85`.

Установка интерфейса и шрифтов:

```powershell
& '.\Russian_Patch\scripts\cors3_cyrillic.ps1'
& '.\Russian_Patch\scripts\cors1_cyrillic.ps1'
& '.\Russian_Patch\scripts\book_cyrillic.ps1'
& '.\Russian_Patch\scripts\install_main_menu.ps1'
```

Ручное преобразование CRK выполняет `tools\crk_codec.ps1`. Формат использует простое
смещение каждого байта на 127 по модулю 256.

## Книжные описания миссий

Книжные описания находятся в `INT` и содержат директиву `>BOOK`. Под
`data\missions` найдено 54 таких файла. Остальные `.ENG` нельзя автоматически
считать книжными описаниями.

Служебные директивы:

- `>BOOK` — начало книги;
- `>PAGE` — новая страница;
- `>TEXT` — начало текста;
- `>T.` — конец текстового блока;
- `>P.` — конец страницы;
- `>B.` — конец книги.

При переводе сохранять количество и порядок директив и пустых блоков. Пустые
блоки могут управлять вертикальными отступами. Использовать полный перевод; не
сокращать текст заранее.

Схема имён исходников:

```text
Russian_Patch\translations\MIS##_COLOR_INT##COLOR.utf8.txt
Russian_Patch\translations\MIS##_COLOR_MSG_MIS##COLOR.utf8.txt
```

Установка подготовленных книжных описаний:

```powershell
& '.\Russian_Patch\scripts\install_mission_translations.ps1'
```

Установщик `install_mission_translations.ps1` обрабатывает только `INT`. Файлы
`_MSG_` устанавливаются отдельно скриптом `install_msg_translations.ps1`;
`manage_msg_translations.ps1` сохранён для точечной работы с первым MSG.

Уже переведены:

- `MIS01`: BLU, ORA, RED, YEL;
- `MIS02`: BLU, ORA, RED, YEL;
- `MIS03`: BLU, ORA, RED, YEL;

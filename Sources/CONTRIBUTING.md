# Улучшение перевода

## Подготовка

Для работы с готовым выпуском запустите `Prepare_Translation_Workspace.cmd` и
укажите каталог установленной игры. Будет создан каталог
`Russian_Patch` с исходниками, скриптами и инструментами.

При клонировании репозитория поместите каталог `Russian_Patch` в корень игры либо
передавайте путь к игре через параметр `-GamePath`, если он предусмотрен
конкретным скриптом.

## Редактирование миссий

Файлы `translations/*.utf8.txt` содержат полный набор из 54 описаний INT и 54
файлов сообщений MSG. Сохраняйте их в UTF-8 и не меняйте служебные директивы,
заголовки секций или количество структурных строк.

После редактирования установите исходники в игру:

```powershell
& '.\Russian_Patch\scripts\install_edited_translations.ps1'
```

Скрипт преобразует все 108 файлов в Windows-1251 с CRLF и проверит отсутствие
неподдерживаемого длинного тире U+2014.

## Проверка

В полной локальной среде с оригиналами в исключённом из Git каталоге `backup/`
выполните:

```powershell
& '.\Russian_Patch\scripts\verify_translation_state.ps1'
& '.\Russian_Patch\scripts\audit_repository.ps1'
```

Затем полностью перезапустите игру и проверьте изменённые страницы или сообщения
непосредственно в соответствующей миссии.

## Сборка автономного выпуска

```powershell
& '.\Russian_Patch\scripts\build_portable_patch.ps1'
```

Готовый развёрнутый каталог создаётся локально в `releases/`. Его содержимое
можно использовать как корень отдельного GitHub-репозитория выпуска.

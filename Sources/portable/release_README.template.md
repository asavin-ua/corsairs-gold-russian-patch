# Русификатор Corsairs Gold

Готовый комплект русификации английского издания Corsairs Gold. Репозиторий
содержит установщик, подготовленные игровые ресурсы и полные исходники перевода.

## Установка

1. Скачайте или клонируйте репозиторий.
2. Закройте игру.
3. Запустите `Install_Russian_Patch.cmd`.
4. Если игра не найдена автоматически, укажите каталог с `corsairs.exe`.

Обычная установка не создаёт постоянную резервную копию. Для установки с
возможностью восстановления используйте `Install_With_Backup.cmd`.

Поддерживается английский `corsairs.exe` с SHA-256:

```text
93FD792E80EC085F36BE814A4A244E96FDCB32CE3010F7B91064836C7FC02FE2
```

Проверка установленного патча: `Verify_Russian_Patch.cmd`.

## Состав репозитория

- `payload/` — 112 готовых переводных ресурсов;
- `Sources/translations/` — 54 исходника INT и 54 исходника MSG в UTF-8;
- `Sources/scripts/` — установка, проверка и сборка;
- `Sources/tools/` — инструменты MSG/CRK и локальные зависимости;
- `Sources/docs/` — технические заметки проекта.

Для редактирования перевода запустите `Prepare_Translation_Workspace.cmd`.
Подробности находятся в [Sources/CONTRIBUTING.md](Sources/CONTRIBUTING.md).
Инструкции для LLM вынесены отдельно в [AGENTS.md](AGENTS.md).

Оригинальные файлы игры и персональные локальные пути в репозиторий не входят.

## Известное ограничение

Надписи `INTRO`, `NAVIGATE`, `FLEE` и `CREDITS` на стартовом экране остаются
английскими: они нарисованы непосредственно в 16-битных TGA-текстурах.
